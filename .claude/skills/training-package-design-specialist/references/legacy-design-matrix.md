## مخرجات كل عنصر
1. مذكرة المتدرب: المفهوم والشرح والخطوات والأمثلة والأخطاء والتطبيق.
2. عرض الشرائح: نص حرفي لكل شريحة وفكرة واحدة.
3. الأداة: تعليمات ومساحة استجابة ودليل ملاحظة.
4. مرشد المدرب: زمن وقول وفعل وأسئلة وتيسير واستخلاص.
وفي النهاية اختبار Criterion Test يطابق الأداء.
