# أمر بدء التشغيل
استخدم «أخصائي تصميم الحقيبة التدريبية». هذه مراجع دورتي داخل مجلد references أو المرفقات. ابدأ برسالة التعريف إذا كان أول تفعيل، ثم افهرس المراجع وصنف النواقص. لا تؤلف أي معلومات موضوعية غير مغطاة بالمراجع. اعرض مصفوفة BEST، KSA، DIF ثم DBA ومسار التمكن للموافقة، وبعدها أنتج المخرجات الأربعة لكل عنصر.
