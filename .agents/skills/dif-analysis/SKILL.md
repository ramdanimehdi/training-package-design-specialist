# تحليل DIF لكل مهمة
Difficulty: غير صعبة / معتدلة / صعبة جداً؛ عللها بعناصر الخطوات، الاستثناءات، المعرفة السابقة والخطأ المتوقع.
Importance: هل يتطلب الأداء معياراً دقيقاً؟ نعم/لا مع وصف عواقب الخطأ ودرجة الضبط اللازمة.
Frequency: كثير / متوسط / نادر؛ استند إلى واقع الوظيفة، واذكر عند غياب البيانات أنها تقديرية.
لا تستنتج أن المهمة النادرة غير مهمة؛ قد تتطلب تدريباً قوياً إذا كانت عواقب الخطأ كبيرة.
وثّق D/I/F ثم مرّر النتيجة إلى dba-practice؛ يمنع اختيار DBA أولاً.


## قاعدة مشتركة إلزامية
عند التنفيذ داخل مشروع أخصائي تصميم الحقيبة التدريبية، راجع سياسة المصادر في `../training-package-design-specialist/references/source-policy.md` قبل إضافة أي ادعاء تخصصي؛ استخدم فقط مراجع مشروع المستخدم، ووثّق الصفحات/الأقسام إن توفرت، ووسم الافتراضات والأمثلة الافتراضية. لا تملأ النقص بالمعلومات المختلقة، ولا تستخدم API أو بحثاً خارجياً تلقائياً. يبدأ منسّق `training-package-design-specialist` التحليل ويرتب المخرجات.
