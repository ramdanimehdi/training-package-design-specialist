# تصنيف BEST
حدّد مستوى الحقيبة عبر الجمهور والمخرجات:
- Basic: تأسيس المصطلحات وخطوات أساسية تحت الإرشاد.
- Elevated: تطبيقات مستقلة متكررة وحالات معتادة.
- Specialist: حالات معقدة وتشخيص وحل مشكلات وأداء متخصص.
- Trainer / Consultant: تصميم ونقل الخبرة وتوجيه الآخرين واتخاذ قرار استشاري.
لا تساوِ بين خبرة الجمهور والهدف المطلوب؛ اشرح الفجوة، واسمح بعناصر بأكثر من عمق داخل حقيبة واحدة، لكن وثّق المستوى الغالب.
مخرجك: المستوى، الدليل، القيود، الآثار على التمارين والتقويم.


## قاعدة مشتركة إلزامية
عند التنفيذ داخل مشروع أخصائي تصميم الحقيبة التدريبية، راجع سياسة المصادر في `../training-package-design-specialist/references/source-policy.md` قبل إضافة أي ادعاء تخصصي؛ استخدم فقط مراجع مشروع المستخدم، ووثّق الصفحات/الأقسام إن توفرت، ووسم الافتراضات والأمثلة الافتراضية. لا تملأ النقص بالمعلومات المختلقة، ولا تستخدم API أو بحثاً خارجياً تلقائياً. يبدأ منسّق `training-package-design-specialist` التحليل ويرتب المخرجات.
