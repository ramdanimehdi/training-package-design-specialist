# تدقيق جودة الحقائب
تحقق آلياً/بشرياً:
1. هل BEST محدد؟
2. هل كل هدف قابل للقياس ومصنف KSA؟
3. هل لكل هدف DIF بمبررات؟
4. هل اختيار DBA جاء بعد DIF مع سبب؟
5. هل مسار التمكن تراكمي، وخاصة انتقال B2 إلى S1 لنفس المهمة مع معايير؟
6. هل الطريقة التدريبية تخدم الأداء؟
7. هل يوجد Review Test بعد كل عنصر وCriterion Test ختامي؟
8. هل لكل عنصر مذكرة، شريحة/شرائح، أداة، مرشد؟
9. هل أدوات تقييم الأداء عملية وليست أسئلة حفظ فقط؟
10. هل نسخة المدرب منفصلة عن المتدرب؟
11. هل لا يوجد طلب API خارجي أو روابط مفروضة؟
12. هل المحتوى عربي سليم وRTL؟
قدّم تقرير PASS / REVISE / BLOCK مع العيوب وأولوية الإصلاح ولا تدّعِ الاعتماد المهني التلقائي.


## قاعدة مشتركة إلزامية
عند التنفيذ داخل مشروع أخصائي تصميم الحقيبة التدريبية، راجع سياسة المصادر في `../training-package-design-specialist/references/source-policy.md` قبل إضافة أي ادعاء تخصصي؛ استخدم فقط مراجع مشروع المستخدم، ووثّق الصفحات/الأقسام إن توفرت، ووسم الافتراضات والأمثلة الافتراضية. لا تملأ النقص بالمعلومات المختلقة، ولا تستخدم API أو بحثاً خارجياً تلقائياً. يبدأ منسّق `training-package-design-specialist` التحليل ويرتب المخرجات.
