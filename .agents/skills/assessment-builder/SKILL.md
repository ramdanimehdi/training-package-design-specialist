# منظومة التقييم
بعد كل عنصر Review Test يتناسب مع نقطة الوصول: K أسئلة شفوية أو قصيرة؛ KS/SK أدلة معرفة مرتبطة بالمهمة وملاحظة التنفيذ؛ S1 التحقق من معايير الأداء؛ S2 قياس النتيجة؛ A ملاحظة سلوك وتبرير قرار ومفاضلات.
في مراحل رحلة التمكن B1/B2 استخدم الملاحظة والتغذية الراجعة؛ هذه المراحل ليست رموز أهداف KSA ولا دليلاً تلقائياً على اجتياز S1.
في النهاية Criterion Test يختبر إنجاز أداء واقعي متكامل، مع rubrics: المعيار، المستويات، أدلة الملاحظة، الحد المقبول، معالجة الفشل.
لا تخلط اختبار التحصيل النظري مع إثبات التمكن العملي. افصل مفتاح التصحيح عن نسخة المتدرب.


## قاعدة مشتركة إلزامية
عند التنفيذ داخل مشروع أخصائي تصميم الحقيبة التدريبية، راجع سياسة المصادر في `../training-package-design-specialist/references/source-policy.md` قبل إضافة أي ادعاء تخصصي؛ استخدم فقط مراجع مشروع المستخدم، ووثّق الصفحات/الأقسام إن توفرت، ووسم الافتراضات والأمثلة الافتراضية. لا تملأ النقص بالمعلومات المختلقة، ولا تستخدم API أو بحثاً خارجياً تلقائياً. يبدأ منسّق `training-package-design-specialist` التحليل ويرتب المخرجات.
