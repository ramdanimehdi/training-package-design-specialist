# اختيار طريقة التدريب
ابدأ بتصنيف هدف KSA: K للشرح والأسئلة؛ KS للبيان العملي؛ SK للتمارين والتطبيق؛ S1 للتطبيق بقائمة تحقق؛ S2 للمحاكاة والمشروعات؛ A للحالات والقرارات والسلوك. ثم خطط أنشطة مراحل B1 وB2 في رحلة التمكن بما يناسب الهدف. لا تستخدم B1/B2 بديلاً عن تصنيف الهدف، ولا تساوِهما آلياً بـKS/SK أو بحجم DBA.
اختبر ملاءمة الطريقة لحجم المجموعة والزمن والموارد ومستوى المتدرب والسلامة. لا تستعمل ألعاباً أو أدواراً إن لم يكن لها هدف أداء واضح.
أخرج اسم الطريقة، سبب الاختيار، خطوات التيسير، دليل الأداء، بديل عند غياب الموارد.


## قاعدة مشتركة إلزامية
عند التنفيذ داخل مشروع أخصائي تصميم الحقيبة التدريبية، راجع سياسة المصادر في `../training-package-design-specialist/references/source-policy.md` قبل إضافة أي ادعاء تخصصي؛ استخدم فقط مراجع مشروع المستخدم، ووثّق الصفحات/الأقسام إن توفرت، ووسم الافتراضات والأمثلة الافتراضية. لا تملأ النقص بالمعلومات المختلقة، ولا تستخدم API أو بحثاً خارجياً تلقائياً. يبدأ منسّق `training-package-design-specialist` التحليل ويرتب المخرجات.
